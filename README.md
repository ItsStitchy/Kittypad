Kittypad is a custom 4-key macropad featuring an EC11 rotary encoder and an integrated OLED display subsystem built using the Seeed Studio XIAO form factor. 

The ultimate goal for this hardware ecosystem is to run an interactive, embedded virtual pet (Tamagotchi-style) utilizing pixel art frame buffers mapped directly over I2C communication lines.

## 🛠️ Hardware Features
* **Microcontroller:** Seeed Studio XIAO
* **Keys:** 4 mechanical switches (Direct-pin layout to Ground)
* **Rotary Encoder:** 1 EC11 volume scroller with a press-to-mute button mapping.
* **Display Interface:** SSD1306 I2C OLED display ready for custom pixel rendering.
* **RGB Flare:** 1 onboard/underglow WS2812B NeoPixel.
